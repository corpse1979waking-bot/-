# Новые функции для улучшения проекта "База звонков"

## Анализ текущего состояния

Проект представляет собой Telegram-бота для учёта входящих звонков с базовой функциональностью:
- ✅ Пошаговая и быстрая запись звонков
- ✅ Напоминания с инлайн-кнопками
- ✅ Поиск и редактирование записей
- ✅ Выгрузка в Excel
- ✅ REST API (Flask)
- ✅ Базовая система пользователей и комментариев (не используется в боте)

## 🔥 Предложения по улучшению

### 1. Многопользовательский режим (Priority: HIGH)

#### 1.1 Система ролей и прав доступа
```python
# Роли:
- admin      — полный доступ, управление пользователями, статистика
- operator   — создание/редактирование звонков, работа с назначенными
- guest      — только просмотр назначенных звонков
```

**Функции:**
- Регистрация новых пользователей через `/register`
- Одобрение заявок администратором
- Разграничение прав на команды
- Персональные списки звонков (`/my_calls`)

#### 1.2 Назначение исполнителей
```python
# Команды:
/assign <ID> @username  — назначить звонок на пользователя
/unassign <ID>          — снять назначение
/take <ID>              — взять звонок в работу себе
```

**Функции из `database_enhanced.py`:**
- `assign_call()` — назначение с логированием
- `get_my_calls()` — список моих звонков
- `get_unassigned_calls()` — свободные звонки для распределения

#### 1.3 Уведомления о назначениях
- Отправка уведомления пользователю при назначении звонка
- Упоминание в комментарии: "@username возьми звонок #123"

---

### 2. Улучшенная воронка статусов (Priority: HIGH)

#### 2.1 Расширенные статусы
```
Новый → В работе → На связи → Закрыт/Не заинтересован
         ↓            ↓
      Отложен ←──────┘
```

**Команды:**
```
/status <ID> <новый_статус>  — изменить статус
/statuses                    — показать все статусы и их переходы
```

**Функции из `database_enhanced.py`:**
- `get_valid_transitions()` — допустимые переходы
- `can_transition()` — проверка возможности перехода
- `get_calls_by_status()` — фильтрация по статусу
- `bulk_status_change()` — массовое изменение статуса

#### 2.2 Автоматические переходы
- При назначении → автоматически "В работе"
- При истечении напоминания без ответа → "Отложен"
- Просроченные звонки → выделение цветом/маркером

---

### 3. История изменений (Audit Log) (Priority: MEDIUM)

#### 3.1 Логирование всех действий
```python
# Таблица audit_log хранит:
- кто изменил (user_id)
- что изменил (action: create/update/delete/assign/status_change)
- какое поле (field)
- старое значение (old_value)
- новое значение (new_value)
- время изменения (created_at)
```

**Команды:**
```
/history <ID>  — показать историю изменений звонка
```

**Функции из `database_enhanced.py`:**
- `log_change()` — запись изменения
- `get_call_history()` — получение истории
- `update_call()` / `delete_call()` — с автоматическим логированием

## 💡 Дополнительные идеи

1. **Голосовые сообщения** — транскрибация через Whisper API

3. **Календарь** — визуальное отображение напоминаний
4. **Интеграция с телефонией** — автоматическое создание звонков из Call-центра
5. **Чат-бот для клиентов** — самостоятельная запись на звонок
